# Imperial Column

Davis's own type family (Text: regular, italic, bold, bold italic), used by Course of Empire (`arcadia`) only. Times New
Roman widths, stems drawn as columns. Built on Liberation Serif 2.1.5, under the SIL Open Font License 1.1
(https://openfontlicense.org). The font files are WOFF2 conversions from the family's specimen page.
